# きくみみ（kikumimi）

聞く耳を持つ、介護のためのAI話し相手。

要介護者の話し相手になるAIチャットと、会話から「いつもと違う様子」を検知して介護者に知らせるダッシュボードを提供します。会話データはローカルSLMで処理し、外部に送信しません。

## 主な機能
- 🗣️ 音声・テキストで話せるAIチャット（利用者向け）
- 🔔 会話からの異変検知とアラート（管理者向け）
- 📝 体調記録・要望フォーム
- 👥 管理グループと利用者の管理

## 技術スタック
| 領域 | 技術 |
|---|---|
| フロントエンド | Next.js (App Router, SSR) / TypeScript |
| バックエンド | FastAPI / Python |
| DB | MySQL |
| LLM | Ollama（ローカルSLM） |
| 音声 | ローカルSTT / VOICEVOX |
| 開発 | Spec Kit / git worktree / Claude Code |
